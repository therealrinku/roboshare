## Contribute to the Project

To run this project locally, follow these steps:

1. Clone the repository.
   ```bash
   git clone https://github.com/therealrinku/roboshare.git

2. Install the dependencies.
   ```bash
   yarn install
   
3. Get your firebase app config with storage setup and add it to the .env file(make sure to match env variable name from firebase.js file

4. Run the project.
   ```bash
   yarn run dev
